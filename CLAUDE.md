# CLAUDE.md — AIBar (папка AI_Dashboard)

Windows-приложение: иконка в трее с радиальным индикатором квот AI-провайдеров,
всплывающий дашборд и виджет поверх окон. Python + PySide6, собирается в exe и
раздаётся релизами. Репозиторий **публичный**: `github.com/SLem233/AIBar`.
Полное описание поведения — в `README.md`, он же документация для пользователя.

## Устройство

| Где | Что |
|---|---|
| `aibar/providers/` | по модулю на провайдера (claude, codex, copilot, cursor, gemini, grok, kimi, openai_api, opencode, tavily, zai), общий контракт в `base.py` |
| `aibar/ui/` | дашборд, виджет и его плитки, ховер-панель, индикаторы, плашки, сворачивание у края |
| `aibar/polling.py` | цикл опроса лимитов |
| `aibar/geoblock.py` | анонимная проба перед опросом: при 403 токены не отправляются вовсе |
| `aibar/config.py` | пользовательские настройки, позиция и размер виджета |
| `aibar/update.py` | часовая сверка версии с последним релизом на GitHub |
| `run_aibar.py`, `AIBar.bat` | запуск из исходников |
| `AIBar.spec` | сборка exe (PyInstaller) |

Версия — `aibar/__init__.py`, `__version__`. Зависимости — `requirements.txt`
(PySide6, requests, Markdown); отдельного venv в папке нет.

## Как работать

```
python -m pytest tests/ -q      # тесты
python run_aibar.py             # запуск из исходников
```

Выпуск новой версии (exe → GitHub Release → корпоративная папка) — скиллом
`release`, а не руками: там же бампается `__version__`.

## Правила, специфичные для этого проекта

- **Репозиторий публичный.** Токены, ключи и внутренние адреса не должны
  попадать ни в код, ни в конфиги, ни в скриншоты `docs/`.
- **Контакты автора живут только в рабочей копии.** Блок в `README.md` между
  `<!-- contacts:start -->` и `<!-- contacts:end -->` вырезается clean-фильтром
  `stripcontacts` при коммите (фильтр в этой копии настроен). Проверять
  результат не глазами, а `git show :README.md`.
- **UI трогает живой экран.** Правки виджета (позиция, сворачивание у края,
  мини-режим) проверяются запуском, а не только тестами: геометрия и
  многомониторные конфигурации в тестах воспроизводятся частично.
- **Провайдер добавляется модулем в `aibar/providers/`** по контракту
  `base.py`, а не правкой общего кода опроса.
- **Недоступность провайдера — не ошибка приложения.** Гео-блок (403) и
  отсутствие VPN отображаются плашкой и значком, кольца держат последние
  значения; молча обнулять нельзя.
