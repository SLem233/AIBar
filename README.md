# AIBar — дашборд лимитов AI-провайдеров для Windows

Аналог [CodexBar-KDE](https://github.com/EvilFreelancer/CodexBar-KDE) для Windows:
иконка в системном трее с радиальным индикатором квот + всплывающий дашборд
с карточками провайдеров.

Репозиторий: **https://github.com/SLem233/AIBar** · готовый exe —
в [Releases](https://github.com/SLem233/AIBar/releases).

![Дашборд](docs/dashboard.png)

## Что показывает

- **Иконка в трее** — два кольца: сессия (синее, внешнее) и неделя (оранжевое,
  внутреннее) самого загруженного провайдера, в центре — процент сессии.
- **Дашборд** (клик по иконке) — карточка на провайдера: радиальный индикатор,
  тариф, все окна лимитов с процентами и обратным отсчётом до сброса,
  дополнительные кредиты. Список карточек не вырастает выше экрана: когда
  провайдеров становится больше, чем помещается, он прокручивается колесом,
  а шапка с кнопкой «Обновить» и подпись с версией остаются на виду.
- **Виджет на рабочем столе** (включён по умолчанию) — полупрозрачная колонка
  круговых индикаторов по провайдерам, висит поверх всех окон:
  - перетаскивается мышью за середину;
  - размер меняется за любую сторону и любой угол рамки: курсор в 8 px от
    края превращается в стрелку изменения размера, кадр не выпускается за
    границы экрана (позиция и размер запоминаются);
  - **ориентация подстраивается под край**: у левого и правого края виджет —
    колонка колец, у верхнего и нижнего — ряд. Ориентация меняется прямо во
    время перетаскивания, как только кадр коснулся края, и там же виджет
    дожимается вплотную; сам кадр при этом переворачивается вокруг центра
    (ширина и высота меняются местами), поэтому кольца сохраняют размер;
  - **под именем провайдера — время до ближайшего сброса** («2д 3ч», «5ч 12м»,
    «43м»); строка не появляется, когда сбрасывать нечего. На узкой плитке
    подписи не исчезают, а укорачиваются многоточием (полное имя — в
    подсказке); совсем пропадают, только если места не остаётся даже под
    многоточие. По высоте место уступают кольцу по очереди: сначала уходит
    отсчёт, потом имя;
  - при наведении мыши рядом всплывает панель с расширенной информацией
    и кнопкой «Обновить» — тот же дашборд, что и по клику на иконку в трее;
  - правый клик — меню (обновить / мини-режим / сворачивание у края /
    настройки / справка / скрыть / выход), включается и выключается
    из меню трея («Виджет поверх окон»);
  - **сворачивание у края экрана** («Сворачивать у края экрана» в меню,
    по умолчанию выключено) — виджет, прижатый к краю, через 0.4 с без
    курсора плавно уезжает за этот край и оставляет полоску ~3.5 мм:
    видно, где он спрятался. Наведение на полоску так же плавно
    возвращает его вплотную к краю. Виджет, висящий с заметным разрывом
    (больше 8 px), не сворачивается — остаётся на месте. Полоска задана
    в миллиметрах, поэтому одинакова в полном виде и в мини-режиме, при
    любом размере кадра; запоминается позиция у края, а не свёрнутая;
  - **не тонет под чужими окнами** — флага «поверх всех» в Windows хватает
    только до первого чужого окна, поднятого в тот же верхний слой (плеер,
    презентация, оверлей мессенджера, возврат из полноэкранного приложения):
    дальше оно так и висит выше. Приложение возвращает себе верх раз в 1.5 с,
    не перехватывая фокус и не мигая окном. Свёрнутому виджету это важнее
    всего: перекрытую полоску не видно и развернуть его нечем;
  - **мини-режим** — на виджете остаются только провайдеры, у которых
    какой-либо лимит израсходован на 70%+ (`mini_threshold` в конфиге).
    Если таких нет — показывается один: тот, чьи лимиты активнее всего
    росли за последние 15 минут, а при полном затишье — показанный
    последним. Ховер-панель и дашборд из трея всегда показывают всех.
- **Справка** — пункт «Справка» в меню виджета и трея открывает встроенную
  HTML-инструкцию (`aibar/resources/help.html`) в браузере.
- **Проверка обновлений** — раз в час приложение сверяет свою версию с
  последним релизом на GitHub; если вышла новая, на виджете появляется
  плашка «↓ Update available» (клик открывает страницу загрузки).
  Установленная версия показана в меню трея, контекстном меню виджета,
  tooltip иконки и в подписи внизу дашборда/ховер-панели.
- **Работа без VPN** — Claude, Codex и OpenAI API из некоторых сетей
  недоступны (гео-блок, HTTP 403). Перед каждым циклом опроса приложение
  делает один анонимный запрос (без токенов); если он получает 403,
  запросы с токенами к этим трём провайдерам не отправляются вовсе:
  на виджете появляется плашка «⏸ нет VPN», у тайлов — значок ⏸,
  а кольца держат последние полученные значения. Остальные провайдеры
  продолжают обновляться. Как только VPN появляется, опрос оживает сам
  на ближайшем цикле. Детекция каскадная (api.anthropic.com →
  api.openai.com → chatgpt.com): rate-limit (429) и сетевые ошибки не
  считаются блокировкой, при полном отсутствии сети показывается честная
  «Сетевая ошибка», а не «нет VPN».
- **Сбой опроса не гасит кольца** — если очередной запрос не удался
  (ограничение частоты, 5xx, обрыв связи), плитка не обнуляется: кольца
  держат последние удачные значения, рядом появляется значок ⚠, а причина
  видна в карточке дашборда и tooltip трея. Так провайдер не пропадает из
  мини-режима и не выглядит «на нуле» из-за временной ошибки. Данные живут
  так до 6 часов — дальше они уже вводили бы в заблуждение, и кольцо
  честно пустеет. Успешный опрос сразу возвращает всё в норму.

## Провайдеры

| Провайдер | Источник авторизации | API |
|-----------|----------------------|-----|
| Claude (Claude Code) | `~/.claude/.credentials.json` | `api.anthropic.com/api/oauth/usage` |
| Codex (ChatGPT) | `~/.codex/auth.json` | `chatgpt.com/backend-api/wham/usage` |
| Cursor | `%APPDATA%\Cursor\...\state.vscdb` | `cursor.com/api/usage-summary` |
| Z.ai / zcode | API-ключ в настройках или `Z_AI_API_KEY` | `api.z.ai/api/monitor/usage/quota/limit` |
| Kimi (Moonshot) | API-ключ coding-плана или `KIMI_API_KEY` | `api.kimi.com/coding/v1/usages` |
| Grok (xAI) | `~/.grok/auth.json` (вход через grok CLI) | `cli-chat-proxy.grok.com/v1/billing` |
| GitHub Copilot | токен GitHub: настройки, `GITHUB_TOKEN`/`GH_TOKEN` или `gh auth token` | `api.github.com/copilot_internal/user` |
| OpenCode | cookie `auth` с opencode.ai (в настройках) | `opencode.ai/_server` (RPC) |
| Google (Gemini) | вход в `gemini` CLI (`~/.gemini`) | `cloudcode-pa.googleapis.com` (квоты моделей) |
| OpenAI API | Admin-ключ (в настройках) | `api.openai.com/v1/organization/costs` |
| Tavily | API-ключ `tvly-…` или `TAVILY_API_KEY` | `api.tavily.com/usage` |

Провайдеры включаются в **Настройках** (меню трея или правый клик по виджету).
Claude, Codex и Cursor работают без ключей — приложение только читает токены,
которые поддерживают сами приложения (`claude`, `codex`, Cursor). Если токен
истёк, достаточно запустить соответствующий CLI/приложение.

**Claude без запуска CLI.** Протухший токен приложение меняет само: берёт
refresh-токен из `~/.claude/.credentials.json`, получает новый и записывает его
обратно в тот же файл. Благодаря этому лимиты видны и тем, кто пользуется
только Claude Desktop. Обмен выключается галочкой «Claude: обновлять протухший
токен самостоятельно» (вкладка «Ключи») — тогда файл только читается, как
раньше, а на истёкшем токене показывается просьба запустить `claude`.
Refresh-токены Anthropic одноразовые, поэтому обмен идёт только когда токен
действительно истёк, а на ответ «токен уже отозван» приложение перечитывает
файл: соседняя сессия (CLI или второй экземпляр AIBar) могла обновить его
первой.

**Ограничение частоты у Claude.** Anthropic лимитирует обращения к эндпоинту
лимитов и отвечает 429 с заголовком `Retry-After`. Приложение его соблюдает:
до истечения паузы запрос не отправляется совсем, кольца всё это время держат
последние значения со значком ⚠, а в карточке написано, через сколько будет
повтор. Тариф берётся из отдельного запроса к профилю и кэшируется на час —
он меняется несопоставимо реже опроса, а лишний запрос удваивал бы нагрузку на
те же ограниченные эндпоинты. Если 429 стал появляться часто, помогает больший
интервал обновления в настройках.

Для **Z.ai (zcode)** нужен API-ключ coding-плана: z.ai → Manage API Key →
Coding Plan (или bigmodel.cn для китайского региона — переключатель в
настройках). Для **OpenCode** — cookie `auth` со страницы opencode.ai
(DevTools → Application → Cookies), workspace `wrk_…` определяется
автоматически.

**OpenAI API** показывает расход за текущий месяц через Costs API — нужен
именно **Admin-ключ** (platform.openai.com → Settings → Organization →
Admin keys), обычный ключ проекта получает 401. Баланс предоплаченных
кредитов OpenAI по API не отдаёт, поэтому остаток считается от «якоря»:
введите в настройках остаток со страницы биллинга и дату — дальше приложение
само вычитает из него расходы Costs API. Бюджет $/мес даёт кольцо
«потрачено % от бюджета».

Для **Kimi** нужен API-ключ coding-плана (platform.moonshot.ai). Показываются
окно сессии (5 ч), недельное окно и остаток кредитов — какие из них вернёт
API, те и рисуются.

**Grok (xAI)** работает от входа в `grok` CLI: токен читается из
`~/.grok/auth.json` и обновляется по OIDC (галочка «Grok: обновлять протухший
токен самостоятельно»). Показывается **расход за расчётный период** подписки
(«Мес. (списание)» или «Неделя (списание)» — по длине периода) и сумма
`$потрачено / $лимит`; обратный отсчёт идёт до конца периода.

Оговорка: на подписках, переведённых на общий пул (SuperGrok и подобные),
HTTP `/v1/billing` отдаёт нулевой лимит и пустую историю. Сам CLI тот же
процент уже кладёт в `~/.grok/logs/unified.jsonl` (строка
`billing: fetched credits config`) — карточка берёт последнюю такую запись,
если в HTTP нет ни процента, ни лимита. По HTTP «Weekly limit» по-прежнему
недоступен: живы только `/v1/billing` и `/v1/user`, TUI ходит за процентом
по WebSocket-реле. Разбор unified-схемы в провайдере есть и сработает и по
HTTP, если ручку откроют. API-ключ XAI бесполезен: публичный `api.x.ai`
лимиты по ключу не отдаёт.

**GitHub Copilot** читает квоты чата, автодополнений и premium-запросов.
Ключ заводить не обязательно: если поле в настройках пустое, токен берётся из
`GITHUB_TOKEN`/`GH_TOKEN`, а затем из `gh auth token` (gh CLI хранит его в
хранилище учётных данных Windows, файла с токеном нет). Оговорка: публичного
API квот Copilot для личного аккаунта не существует, используется внутренний
эндпоинт расширения Copilot Chat — он может измениться в любой момент, и тогда
провайдер покажет ошибку. Безлимитные квоты (планы Pro) выводятся кольцом на
нуле с пометкой «∞», не выданные (entitlement = 0) не показываются вовсе.

**Google (Gemini)** — квоты моделей (Pro/Flash) через OAuth Gemini CLI;
нужен один раз выполненный вход в `gemini`. Баланс и траты AI Studio API
Google программно не отдаёт (только дашборд AI Studio). **Tavily** — обычный
ключ, квота кредитов плана. **Serper.dev** не поддержан: у него нет API для
баланса.

## Установка и запуск

Готовый exe: `dist\AIBar.exe` — запускается двойным кликом, ничего
устанавливать не нужно.

Из исходников:

```powershell
pip install -r requirements.txt
# запуск без консоли
.\AIBar.bat
# или с консолью (для отладки)
python -m aibar.main
```

Пересборка exe:

```powershell
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name AIBar --icon assets\aibar.ico --add-data "aibar/resources;aibar/resources" run_aibar.py
```

### Автозапуск

Скопировать ярлык на `dist\AIBar.exe` (или `AIBar.bat` при запуске из
исходников) в папку автозагрузки: `Win+R` → `shell:startup`.

`%APPDATA%\AIBar\config.json`:

```json
{
  "refresh_seconds": 300,
  "providers": ["Claude", "Codex", "Cursor"],
  "widget_enabled": true,
  "widget_geometry": [1650, 60, 120, 260],
  "widget_horizontal": false,
  "widget_mode": "full",
  "mini_threshold": 70,
  "zai_api_key": "",
  "zai_region": "global",
  "kimi_api_key": "",
  "copilot_token": "",
  "claude_auto_refresh": true,
  "grok_auto_refresh": true,
  "opencode_cookie": "",
  "opencode_workspace": "",
  "openai_admin_key": "",
  "openai_budget_usd": 0,
  "openai_balance_usd": 0,
  "openai_balance_date": "",
  "tavily_api_key": "",
  "claude_renewal_date": "08.08.2026",
  "claude_renewal_period": "month",
  "cursor_renewal_date": "",
  "cursor_renewal_period": "year",
  "zai_renewal_date": "",
  "zai_renewal_period": "year",
  "tavily_renewal_date": "",
  "tavily_renewal_period": "month",
  "kimi_renewal_date": "",
  "kimi_renewal_period": "month",
  "copilot_renewal_date": "",
  "copilot_renewal_period": "month",
  "grok_renewal_date": "",
  "grok_renewal_period": "month"
}
```

`widget_horizontal` — ряд вместо колонки; выставляется сам, когда виджет
переносят к верхнему или нижнему краю экрана.

`*_renewal_date` / `*_renewal_period` — дата ближайшего продления и период
подписки (`month` / `quarter` / `year`) для провайдеров, чьи API не отдают
дату списания; прошедшая дата автоматически сдвигается на период вперёд.
Пустая дата — строка «Продление» не показывается. На карточке дашборда
и ховер-панели эта строка (у Codex — «Подписка до») прижата к нижнему
краю рамки у всех провайдеров; кредиты и расход остаются со строками
лимитов. У Codex дата берётся из API автоматически; у Cursor API отдаёт
только конец месячного расчётного цикла (он показан как «↺ до сброса» у
колец), а дата продления самой подписки задаётся здесь.

Всё это редактируется через диалог «Настройки…» — руками файл трогать не нужно.

Интервал обновления также переключается из контекстного меню иконки в трее.

## Структура

```
aibar/
├── main.py            # трей-приложение, поллинг по таймеру
├── polling.py         # цикл опроса провайдеров (чистая логика, без Qt)
├── geoblock.py        # детекция гео-блока «нет VPN» анонимным запросом
├── config.py          # настройки в %APPDATA%\AIBar
├── theme.py           # тёмная палитра (валидирована по CVD/контрасту)
├── providers/
│   ├── base.py        # модель данных (RateWindow, ProviderSnapshot)
│   ├── claude.py      # Claude OAuth usage
│   ├── codex.py       # Codex (ChatGPT backend) usage
│   ├── cursor.py      # Cursor (usage-summary)
│   ├── zai.py         # Z.ai coding plan (zcode)
│   ├── kimi.py        # Kimi coding plan (Moonshot)
│   ├── grok.py        # Grok (xAI): окно списания подписки
│   ├── copilot.py     # GitHub Copilot (внутренний эндпоинт квот)
│   ├── opencode.py    # OpenCode (opencode.ai)
│   ├── openai_api.py  # OpenAI API (расход за месяц, Costs API)
│   └── tavily.py      # Tavily (кредиты плана)
└── ui/
    ├── gauge.py         # радиальный многокольцевой индикатор (QPainter)
    ├── dashboard.py     # всплывающее окно с карточками
    ├── settings.py      # диалог настроек
    ├── badges.py        # плашки «доступно обновление» и «нет VPN»
    ├── edge_collapse.py # сворачивание виджета за край экрана
    ├── topmost.py       # удержание виджета в верхнем слое окон
    ├── hover_panel.py   # панель с разбивкой, всплывающая у виджета
    └── widget.py        # виджет поверх окон (рамка, ориентация, плитки)
```

## Тесты

```powershell
python -m pytest tests
```

Покрывают детекцию гео-блока, цикл опроса (пауза/восстановление, сохранение
последних данных, удержание колец при ошибке опроса и срок годности этих
данных), `http_status` провайдеров, разбор ответов Kimi, Grok и
Copilot, обмен токенов Claude и Grok (включая 403 как гео-блок, упавшее реле
без лишней ротации токена и выключенный обмен), ограничение частоты у Claude
(соблюдение `Retry-After`, кэш профиля, отсутствие ротации токена на 429),
индикацию несвежих данных, индикацию паузы, сворачивание
виджета у края, удержание виджета в верхнем слое окон, ориентацию по краю,
изменение размера за рамку и отсчёт на плитке в UI (offscreen-Qt).

## Как добавить провайдера

1. Создать `aibar/providers/<name>.py` с функцией `fetch(cfg: dict) -> ProviderSnapshot`.
2. Зарегистрировать её в `PROVIDERS` (и подсказку в `PROVIDER_HINTS`) в
   `aibar/providers/__init__.py`.
3. Включить провайдера в диалоге «Настройки…».
